# PokeIdle 1.0 게임 사용 설명서

현재 Android 1.0 구현 기준입니다. 이 게임은 동료가 자동으로 공격하는 방치형 게임입니다. 팀에 포켓몬을 배치하고 기술·특성·도구를 조합해 성장시키세요.

## 1. 화면과 기본 조작

- **팀동료**: 포켓몬을 선택해 도구 장착, 레벨업, 기술·특성 변경, 변신을 합니다.
- **박스**: 포켓몬 보관, 팀 교체, 진화·합체를 합니다.
- **도감**: 폼, 일반·이로치 모습, 종족치, 기술과 특성 설명을 확인합니다. 아직 해금하지 않은 히든 몬스터는 검색되지 않습니다.
- **상단 툴바**: 누르면 확장되어 DPS, 누적 경험치, 초당 경험치와 도감·환생상점·업적·설정 버튼이 나타납니다.
- **설정**: 음악·효과음 음량, 다크모드와 크레딧을 확인합니다. 날씨에 따라 전투 배경 효과도 달라집니다.

도구는 포켓몬 한 마리당 하나씩 장착합니다. 같은 도구를 여러 마리에게 주려면 장착할 수량만큼 보유해야 합니다.

## 2. 메가진화

1. 해당 포켓몬에 맞는 **메가스톤(나이트)**을 장착합니다.
2. 자동 공격으로 변신 게이지를 채웁니다. 기본 충전량은 타격당 4%입니다.
3. **게이지 100%**에서 팀동료의 메가진화 버튼을 누릅니다.

메가진화하면 해당 폼의 종족치·타입·특성·스프라이트가 적용됩니다. 보유 기술은 유지하며, 일부 전용 예외는 뒤에서 설명합니다. 기본 변신 시간은 30초이고, 메가스톤 장착 변신에는 1.1배 지속시간 보정이 적용되어 일반적으로 33초 유지됩니다. 종료되면 원래 폼으로 돌아갑니다.

나이트 이름에 X·Y·Z가 붙으면 대응하는 폼으로만 변신합니다. 접미사가 없는 단일 메가폼은 해당 나이트를 사용합니다.

## 3. Z기술

1. 선택한 기술에 맞는 **타입 Z크리스탈** 또는 **포켓몬 전용 Z크리스탈**을 장착합니다.
2. 대응 기술로 공격해 게이지를 채웁니다.
3. 게이지가 100%가 되면 **자동으로 발동**합니다. 별도 변신 버튼을 누를 필요가 없습니다.
4. **10초 동안** 선택 기술이 Z기술로 변환되며, 종료 후 원래 기술로 돌아갑니다.

타입 Z크리스탈은 기술 타입이 맞아야 합니다. 전용 크리스탈은 포켓몬과 원본 기술까지 맞아야 합니다. Z크리스탈은 단순한 위력 1.1배 도구가 아닙니다.

## 4. 다이맥스·거다이맥스

1. 변신 가능한 포켓몬에게 **다이버섯**을 장착합니다.
2. 게이지를 100%까지 채웁니다.
3. 팀동료에서 거다이맥스 버튼을 누릅니다.

- 변신은 **30초** 유지됩니다.
- **공격·특공이 1.5배**가 되며 스탯창에도 반영됩니다.
- 전체 종족치가 2배가 되는 방식은 아닙니다.
- 선택 기술은 타입별 다이맥스 기술로 바뀝니다.
- 기술의 **물리·특수 분류는 원본을 유지**합니다.

지원 포켓몬: 이상해꽃, 리자몽, 거북왕, 버터플, 피카츄, 나옹, 괴력몬, 팬텀, 킹크랩, 라프라스, 이브이, 잠만보, 더스트나, 멜메탈, 고릴타, 에이스번, 인텔리레온, 아머까오, 이올브, 갈가부기, 석탄산, 애프룡, 단지래플, 사다이사, 스트린더, 다태우지네, 브리무음, 오롱털, 마휘핑, 대왕끼리동, 두랄루돈, 우라오스. 무한다이노는 무한다이맥스로 변신합니다.

## 5. 특수 규칙이 있는 포켓몬

### 개굴닌자 → 지우개굴닌자

- **유대변화 특성**이면 메가스톤 없이 게이지를 채워 변신할 수 있습니다.
- **지우개굴닌자 나이트**를 장착하는 경로도 있습니다. 일반 개굴닌자나이트와 구분하세요.
- 지우개굴닌자 상태의 물수리검은 **물 타입·특수·위력 90**으로 취급됩니다.

### 지가르데 합체

야생 지가르데는 **10%폼**으로만 출현합니다. 합체 재료는 박스에 모으세요.

1. 박스의 **10%폼 5마리**를 합쳐 **50%폼 1마리**를 만듭니다.
2. 박스의 **50%폼 2마리**를 합쳐 **퍼펙트폼 1마리**를 만듭니다. 두 마리 중 적어도 하나는 **스웜체인지** 특성이어야 합니다.
3. **퍼펙트폼만 지가르데나이트를 장착해 메가진화**할 수 있습니다.

합체 버튼을 누른 개체의 이로치 여부가 결과에 유지됩니다. 선택한 개체가 이로치면 다른 재료가 일반이어도 결과는 이로치입니다. 합체 재료는 소모되므로 확인창을 읽으세요.

코어퍼니셔를 선택했다면 메가진화 중에는 **니힐레이저**로 변경됩니다. 변신 종료 후 원래 기술로 돌아옵니다.

### 네크로즈마 합체와 울트라버스트

- **네크로플러스 솔**: 네크로즈마에 지니게 하면 팀·박스의 솔가레오를 소모해 황혼의 갈기로 변합니다.
- **네크로플러스 루나**: 루나아라를 소모해 새벽의 날개로 변합니다.
- 합체 성공 시 파트너와 아이템이 소모됩니다. 실행 전 확인창을 읽으세요.
- **울트라네크로Z는 황혼의 갈기·새벽의 날개 상태에서만 장착**할 수 있습니다.
- 울트라버스트 종료 후에는 원래의 합체폼으로 복귀합니다.
- 울트라버스트 중 **포톤가이저**를 사용하면 **하늘을 태우는 멸망의 빛**으로 변환됩니다. 다른 기술에는 이 변환이 적용되지 않습니다.

### 아르세우스와 레전드 플레이트

아르세우스 전용 레전드 플레이트를 장착하면 심판의뭉치 계열 전용기(기술 번호 449, 아이템 설명의 ‘멸망의 뭉치’)는 **상성 우위·확정 급소·명중 보장** 효과를 받습니다.

## 6. 종족치와 실제 전투력

종족치 합계만으로 전투력이 정해지지 않습니다. 현재 폼의 능력치, 선택 기술, 레벨, 공격 주기, 도구와 팀 효과를 함께 봐야 합니다.

| 능력치 | 이 게임에서의 주요 역할 |
|---|---|
| 공격 | 물리 기술의 기본 피해 계산 |
| 특공 | 특수 기술의 기본 피해 계산 |
| 스피드 | 자동 공격 간격 단축 |
| 방어 | 능력 랭크 저하에서 회복하는 속도 |
| 특방 | 상태이상에서 회복하는 속도 |
| HP | 적으로 출현했을 때 최대 체력 산정에 사용. 아군 공격력에 직접 합산하지 않음 |

팀 스탯창에서 공격·특공 중 높은 쪽은 **빨간색 굵은 글씨**로 표시됩니다. 두 값이 같으면 둘 다 강조됩니다. 물리 기술은 공격을, 특수 기술은 특공을 사용하므로 높은 쪽과 기술 분류를 맞추는 것이 유리합니다.

### 피해와 공격 주기 읽는 법

다른 효과가 없을 때의 기본 피해 규모는 다음 구조입니다.

```text
기본 피해 ∝ 선택 기술에 대응하는 공격 또는 특공 × 0.25
          × 1.1^(레벨−1)
          × 성장 강화·도감·환생 강화·환생 특전 보정

최종 피해 ∝ 기본 피해 × (기술 위력 / 50)
          × 자속 × 타입 상성 × 급소
          × 날씨·필드·특성·도구·상태·적 방어 효과
```

- 자신의 현재 타입과 기술 타입이 같으면 **자속 2배**를 받습니다.
- 일반 급소는 기본적으로 **1.5배**이며 일부 특성·도구가 추가 보정합니다.
- 환생상점 개별 포켓몬 강화는 회당 **피해 1.3배**입니다.
- 다이맥스는 공격·특공에 앞서 설명한 **1.5배**를 적용합니다.
- 폼 변환 시 새 폼의 종족치가 사용됩니다.

기본 공격 간격은 `최대(0.5초, 3초 − 스피드/60)`입니다. 여기에 특성·도구·강화·마비 등의 보정이 붙습니다. 따라서 강한 한 방과 빠른 공격은 서로 다른 장점입니다. 상단 **DPS**와 실제 처치 속도를 함께 비교하세요. 매우 빠른 공격은 엔진에서 여러 타격을 묶어 계산할 수 있습니다.

방어·특방의 회복 속도 배율은 각각 `종족치/70`이며, 최소 0.5배·최대 3배 범위입니다. 치료 버튼을 누르면 상태 회복을 도울 수 있습니다.

## 7. 이로치 수집과 환생상점

이로치는 야생에서 만날 수 있으며, 만나기와 실제 포획은 별개의 기록입니다. 포켓몬 마스터 칭호에는 **이로치 포획·획득 기록**이 필요합니다.

환생상점에서는 팀과 박스를 이름·도감 번호로 검색할 수 있습니다. 일반 포켓몬을 **마스터볼 50개**로 이로치로 바꿀 수 있으며, 변환 결과는 수집 기록에 반영됩니다. 히든 몬스터는 이로치로 바꿀 수 없습니다.

포맷은 포켓몬을 삭제하고 성장 재화 일부를 환급하는 기능입니다. 방생 기능은 제거되어 있으며 **히든 몬스터는 포맷할 수 없습니다**.

## 8. 숨겨진 포켓몬과 칭호 보상

이 절에는 히든 몬스터 해금 조건이 포함되어 있습니다.

| 칭호·조건 | 보상 |
|---|---|
| 수집가: 히든을 제외한 **도감 1~1025번 모두 수집** | **1026번 OO OOO Lv.100** 박스 지급 |
| 포켓몬 마스터: **기본 1025종과 리전 폼을 일반·이로치로 모두 수집** | **1027번 OOO OOO Lv.100** 박스 지급 |

- 보상은 조건 달성 시 자동 지급되며 중복 지급되지 않습니다.
- 해금 전 히든 몬스터는 도감 목록·검색에 나타나지 않습니다. 보상으로 얻으면 도감이 활성화됩니다.
- 히든 몬스터는 야생 적으로 출현하지 않으며 **이로치가 없습니다**.
- 두 히든 몬스터는 수집가·포켓몬 마스터의 선행 수집 대상에 포함되지 않습니다.
- 기존 보유 이로치는 수집에 반영됩니다. 이전 버전에서 이미 포맷·방생한 이로치는 당시 별도 포획 기록이 없어 자동 복원되지 않을 수 있습니다.

## 9. 변신이 되지 않을 때

1. 현재 선택한 포켓몬과 장착 도구가 맞는지 확인하세요.
2. 메가진화·거다이맥스·원시회귀는 게이지 100%에서 버튼을 눌러야 합니다.
3. Z기술은 대응 기술을 선택해야 하며 게이지 100%에서 자동 발동합니다.
4. X·Y·Z 메가스톤과 대응 폼, 지가르데 퍼펙트폼 제한을 확인하세요.
5. 네크로즈마는 먼저 합체폼을 만든 뒤 울트라네크로Z를 장착하세요.
6. 선택 기술의 물리·특수 분류와 현재 폼의 공격·특공을 비교하세요.

배포용 1.0에는 디버그 메뉴가 없습니다. 정상 플레이로 수집·강화·변신을 진행할 수 있습니다.

## 10. 일반 상점과 코인
상단 툴바를 펼쳐 일반 상점을 여세요. 적을 처치하면 적 레벨 100당 1코인을 받습니다. 100레벨 미만은 0개, 100~199레벨은 1개, 200~299레벨은 2개입니다. 코인으로 모든 도구를 개당 1코인에 구매할 수 있습니다. 이름·설명 검색과 보유 수량 확인을 지원하며 구매 후 자동 저장됩니다.
